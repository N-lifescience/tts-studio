# TTS 작업실 웹앱 — 계획

터미널 없이 맥 브라우저에서 대본 → 내 목소리 나레이션 → 루마퓨전(아이패드)까지 가는 작업 공간.

## 정해진 것

| 항목 | 결정 | 이유 |
|---|---|---|
| 사용 위치 | **맥 브라우저에서만** (`127.0.0.1` 에만 연결) | 네트워크에 안 열어서 로그인·잠금 불필요 |
| 사용자 | 나 혼자 | 계정·동의·처리방침 불필요 (학생 데이터 없음 → dorms edzip 트랙 해당 없음) |
| 편집 툴 | **아이패드 LumaFusion** | XML 타임라인·SRT **불러오기를 지원하지 않음** → 파일 단위로 넘긴다 |
| 아이패드로 넘기기 | **iCloud Drive 자동 저장** `iCloud Drive/TTS/<에피소드>/` | 파일 앱에 자동으로 뜨고, 루마퓨전에서 바로 불러옴 |
| 자막 | **둘 다** — `srt`(유튜브 CC) + **초록 배경 자막 영상**(루마퓨전 크로마키) | |
| 발음 검사 | 음성인식으로 되받아써서 대본과 비교, 틀리면 **자동으로 최대 3번 다시** | 그래도 틀리면 빨간 표시 |
| 톤 | 톤별 목소리 샘플(기본·차분·긴장감 …)을 녹음해 두고 **줄마다 고름** | 복제 모델이 말투 지시를 받지 않음 |

줄마다: 재생 · 발음검사 결과 · 목소리(톤) · 속도(0.8~1.2x) · 뒤 쉼 · 테이크 목록(골라 듣고 채택) · 다시 뽑기.
대본을 고치면 바뀐 줄만 다시 만든다 (지금 `narrate.py` 방식 그대로).

## 내보내기 (iCloud Drive/TTS/<에피소드>/)

```
narration.wav                 전체 나레이션 (48kHz, -14 LUFS) → 루마퓨전 0초에 놓기
narration.srt                 유튜브 CC 업로드용
subtitles_green.mp4           초록 배경 자막 영상 → 루마퓨전 위 트랙 + 크로마키

```

## 구조

- **백엔드**: Python FastAPI — 모델이 파이썬(mlx-audio)이라 같은 프로세스에 올려 둔다.
  GPU는 하나라 **생성 작업은 줄 세워 하나씩** 처리, 진행 상황은 SSE로 화면에 흘린다.
- **프론트**: Vite + React + TypeScript. `innerHTML` 안 씀. 녹음은 브라우저 MediaRecorder.
- **저장**: DB 없이 파일로. `projects/<에피소드>/project.json` + `takes/*.wav`. 목소리는 `voices/`.
  전부 SSD, GitHub 금지(.gitignore).
- **보안**: `127.0.0.1` 바인딩, CSP·`X-Frame-Options` 헤더, 업로드 파일 형식·크기 제한.
- **자막 영상**: 설치된 ffmpeg에 자막 필터(libass)가 없음 → Pillow로 줄별 자막 PNG를 그리고
  ffmpeg로 길이 맞춰 이어 붙임. 글꼴 Apple SD Gothic Neo, 테두리 넣어 크로마키 번짐 방지.

## 순서

1. **기본 편집기** — 에피소드·대본·줄 목록, 생성/다시뽑기/테이크 채택, 전체 듣기, wav·srt·조각 → iCloud
2. **자동 발음 검사** — 되받아쓰기 비교(글자 오차율), 자동 3회 재시도, ⚠️ 표시 + "무시" 버튼
3. **목소리 관리** — 웹에서 녹음·업로드, 자동 받아쓰기 후 고치기, 줄별 목소리·속도·쉼
4. **초록 자막 영상** — 글꼴·크기·위치 설정, mp4 생성

각 단계 끝나면 실제 에피소드 하나로 루마퓨전까지 넣어 보고 다음으로.

## 먼저 확인할 위험

- **메모리 16GB**: TTS 단독 최대 약 12.5GB를 봤다. 음성인식(1.7B, 2.5GB)까지 같이 올리면 빠듯하다.
  → 1단계에서 MLX 캐시 상한을 걸고 음성인식은 0.6B-8bit로 바꿔서 실측한 뒤 정한다.
- **발음 검사 오탐**: "공허→공어", "낫처럼→나처럼"처럼 소리 나는 대로 받아쓰는 경우.
  → 기준을 느슨하게 잡고 "무시" 버튼을 둔다. 실제 에피소드로 기준값을 맞춘다.
- **속도 조절 음질**: 만든 뒤 늘이기(`atempo`)라 0.8x 아래·1.2x 위는 부자연스러울 수 있다.
